Proyecto Final

Instrucciones
Diseñar y desarrollar un proyecto de Ciencia de Datos aplicando principios metodológicos, conectando múltiples fuentes de datos heterogéneas y comunicando hallazgos de forma clara y reproducible.



Objetivos específicos

Formular una pregunta de análisis de datos con valor aplicado.

Diseñar o seleccionar una base de datos estructurada en MySQL, PostgreSQL o MongoDB (o combinación).

Desarrollar un flujo de extracción, transformación y carga de datos (ETL).

Aplicar técnicas de análisis exploratorio de datos para extraer hallazgos relevantes.

Documentar todo el proceso de forma clara, reproducible y con enfoque narrativo para publicación en Medium.



El desarrollo del proyecto debe seguir el enfoque CRISP-DM, con etapas claramente diferenciadas:

Comprensión del problema

Comprensión y conexión a los datos

Preparación de los datos

Análisis exploratorio (Series de tiempo)

(Opcional) Modelado básico

Conclusiones accionables
